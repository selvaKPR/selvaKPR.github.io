🟢 Basic Level

01
Name Tag Maker
Basic
Task

Ask the user for their first name and last name. Print a formatted name tag that shows their full name in title case, their initials, and the total number of characters in their full name (without the space).

Input
first = "alice"
last = "sharma"
Expected Output
Name : Alice Sharma
Initials : A.S.
Length : 11 chars
Use .title() to fix case, [0] to get initials, and len() on the concatenated name (without space). Try an f-string to print all at once.
.title() indexing [0] len() f-string concatenation
02
String Inspector
Basic
Task

Given any string, print a short report showing: the original string, its length, the first character, the last character, and the string reversed.

Input
text = "Python"
Expected Output
Original : Python
Length : 6
First : P
Last : n
Reversed : nohtyP
Use text[0] for first, text[-1] for last, and text[::-1] to reverse. Use len() for length.
indexing slicing [::-1] len() f-string
03
Messy Input Cleaner
Basic
Task

A user typed their email address carelessly — it has extra spaces and random uppercase letters. Clean it up: remove all leading/trailing spaces and convert the whole thing to lowercase.

Input
email = " ALIce.Sharma@Gmail.COM "
Expected Output
Cleaned: alice.sharma@gmail.com
Chain two methods together: .strip() removes spaces, .lower() makes it lowercase. You can do both in one line: email.strip().lower().
.strip() .lower() method chaining

🔵 Intermediate Level

04
Username Generator
Intermediate
Task

Given a full name and a birth year, generate a username by combining: the first 3 letters of the first name (lowercase) + the full last name (lowercase) + the last 2 digits of the birth year.

Input
name = "Alice Sharma"
year = "2001"
Expected Output
Username: alisharma01
Use .split() to separate first and last name. Use [:3] to get first 3 letters of first name. Use [-2:] to get last 2 digits of the year. Concatenate all with +.
.split() slicing [:3] slicing [-2:] .lower() concatenation
05
Vowel Counter
Intermediate
Task

Given a sentence, count how many vowels (a, e, i, o, u) it contains. The check must work regardless of whether letters are uppercase or lowercase. Print the total vowel count.

Input
text = "Hello, I love Python!"
Expected Output
Vowels found: 7
First convert the string to lowercase with .lower(). Then loop through each character and check if it in "aeiou". Use a counter variable that you increment each time.
.lower() for loop in operator counter
06
Sentence Reverser
Intermediate
Task

Given a sentence, reverse the order of words (not the characters). The result should be a proper sentence with words separated by a single space.

Input
sentence = "I love learning Python"
Expected Output
Python learning love I
Use .split() to get a list of words, then use list slicing [::-1] to reverse the list, then use " ".join() to put it back together as a string.
.split() list [::-1] " ".join()
07
CSV Row Formatter
Intermediate
Task

You receive a raw CSV line as a string. Split it by commas and print each field neatly on its own line, showing the field number and its value (stripped of any spaces). Also print the total number of fields found.

Input
row = "Alice, 25, Engineer, Bengaluru"
Expected Output
Field 1: Alice
Field 2: 25
Field 3: Engineer
Field 4: Bengaluru
Total fields: 4
Use .split(",") to get a list of fields. Loop through them using enumerate() (or a counter) and call .strip() on each field. Use len() for the total count.
.split(",") .strip() for loop len() f-string

🔴 Advanced Level

08
Palindrome Checker
Advanced
Task

Check whether a given word or phrase is a palindrome — it reads the same forwards and backwards. The check must ignore spaces and case. Print whether it is or isn't a palindrome, and also show the cleaned version used for comparison.

Input Examples
"Racecar"
"A man a plan a canal Panama"
"Hello"
Expected Output
Cleaned: racecar → ✅ Palindrome
Cleaned: amanaplanacanalpanama → ✅ Palindrome
Cleaned: hello → ❌ Not a palindrome
Convert to lowercase with .lower(), then remove spaces with .replace(" ", ""). Compare the cleaned string with its reverse [::-1]. If they match, it's a palindrome.
.lower() .replace() slicing [::-1] comparison == if/else
09
Word Frequency Counter
Advanced
Task

Given a sentence, find and print each unique word and how many times it appears. Convert everything to lowercase before counting. Words are separated by spaces. Print results in the format shown.

Input
text = "the cat sat on the mat the cat"
Expected Output
the → 3
cat → 2
sat → 1
on → 1
mat → 1
Use .lower().split() to get a list of words. Then loop through the list: for each unique word (check with .count() on the words list, or use a dictionary), print the word and its count. Make sure not to print the same word twice.
.lower() .split() .count() for loop in operator tracking seen words
10
Mini Password Validator
Advanced
Task

Write a password validator that checks a given password string against 4 rules. Print a ✅ or ❌ for each rule, and a final verdict. Rules:

  ① At least 8 characters long
  ② Contains at least one uppercase letter
  ③ Contains at least one digit (0–9)
  ④ Contains at least one special character from !@#$%

Input
password = "Hello@99"
Expected Output
✅ Min 8 chars
✅ Has uppercase
✅ Has a digit
✅ Has special char
→ Strong password!
Use len() for rule 1. For rules 2–4, loop through each character and check: uppercase with .isupper(), digit with .isdigit(), special char with char in "!@#$%". Use a boolean flag for each rule that starts as False and becomes True when found.
len() .isupper() .isdigit() in operator for loop boolean flags if/else
