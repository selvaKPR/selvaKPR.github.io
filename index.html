01

Creating Strings

A string is a sequence of characters — letters, digits, spaces, symbols. You can create one using single quotes, double quotes, or triple quotes.

creating_strings.py
# --- Single and Double Quotes ---
name    = 'Alice'          # single quotes
city    = "Bengaluru"     # double quotes (same result)
message = "It's a nice day" # double quotes let you use apostrophe inside

# --- Triple Quotes (for multi-line strings) ---
bio = """Hello!
I am learning Python.
Strings are fun."""

print(name)
print(city)
print(message)
print(bio)
▶ Output
Alice
Bengaluru
It's a nice day
Hello!
I am learning Python.
Strings are fun.
Tip: Single and double quotes are interchangeable. Triple quotes ("""...""" or '''...''') are great for strings that span multiple lines.

Indexing — Accessing Individual Characters

Each character in a string has a position called an index. Python starts counting from 0. Negative indices count from the end.

indexing.py
word = "Python"
#        P  y  t  h  o  n
#  index: 0  1  2  3  4  5
# neg:   -6 -5 -4 -3 -2 -1

print(word[0])   # First character
print(word[3])   # Character at index 3
print(word[-1])  # Last character (negative index)
print(word[-2])  # Second-to-last character
▶ Output
P
h
n
o
03

Slicing — Extracting a Portion

Slicing extracts a sub-string using string[start : end : step]. The end index is not included.

slicing.py
text = "Hello, World!"

print(text[0:5])    # index 0 to 4  →  "Hello"
print(text[7:12])   # index 7 to 11 →  "World"
print(text[:5])     # start omitted → from beginning
print(text[7:])     # end omitted   → to the end
print(text[:])      # copy of the whole string

# --- Using step ---
print(text[::2])    # every 2nd character
print(text[::-1])   # reverse the string!
▶ Output
Hello
World
Hello
World!
Hello, World!
Hlo ol!
!dlroW ,olleH
Remember: text[start:end] — the character at end is NOT included. Think of indices as markers between characters.

Concatenation & Repetition

Use + to join strings together, and * to repeat a string.

concatenation.py
first = "Hello"
second = "World"

# Joining with +
result = first + ", " + second + "!"
print(result)

# Repeating with *
line = "-" * 20
print(line)

# Building a greeting
name     = "Alice"
greeting = "Welcome, " + name + "!"
print(greeting)
▶ Output
Hello, World!
--------------------
Welcome, Alice!

String Length & Common Methods

Python provides built-in methods (functions attached to strings) to perform common operations. They always return a new string — the original stays unchanged.

length_and_case.py
s = "Hello, Python!"

# Length — number of characters
print(len(s))          # 14

# Case conversion
print(s.upper())       # all uppercase
print(s.lower())       # all lowercase
print(s.title())       # Title Case (first letter of each word)
print(s.swapcase())    # swap upper ↔ lower
▶ Output
14
HELLO, PYTHON!
hello, python!
Hello, Python!
hELLO, pYTHON!
strip_replace.py
messy = "   hello world   "

# Remove leading/trailing spaces
print(messy.strip())    # both sides
print(messy.lstrip())   # left side only
print(messy.rstrip())   # right side only

phrase = "I love cats and cats love me"

# Replace a word
print(phrase.replace("cats", "dogs"))
# Replace only the first occurrence
print(phrase.replace("cats", "dogs", 1))
▶ Output
hello world
hello world   
   hello world
I love dogs and dogs love me
I love dogs and cats love me
find_count.py
sentence = "the cat sat on the mat"

# Find the index of first occurrence (-1 if not found)
print(sentence.find("cat"))    # 4
print(sentence.find("dog"))    # -1 (not found)

# Count how many times a substring appears
print(sentence.count("the"))   # 2
print(sentence.count("at"))    # 3 (cat, sat, mat)
▶ Output
4
-1
2
3

Here's a quick reference for the most useful string methods:

Method What it does Example
.upper() Convert to uppercase "hello".upper() → "HELLO"
.lower() Convert to lowercase "HELLO".lower() → "hello"
.strip() Remove whitespace from both ends " hi ".strip() → "hi"
.replace(a, b) Replace all occurrences of a with b "cat".replace("c","b") → "bat"
.find(s) Index of first occurrence (−1 if not found) "hello".find("ll") → 2
.count(s) Count how many times s appears "banana".count("a") → 3
.title() Capitalize first letter of each word "hello world".title() → "Hello World"
len(s) Number of characters in string len("abc") → 3
06

String Formatting

Formatting lets you embed variables inside a string. The modern and recommended way is using f-strings (formatted string literals).

formatting.py
name  = "Alice"
age   = 25
score = 98.5

# --- f-string (modern, recommended) ---
print(f"Name: {name}, Age: {age}")

# You can include expressions directly
print(f"Next year she will be {age + 1}")

# Control decimal places
print(f"Score: {score:.1f}")    # 1 decimal place

# --- .format() method (older style) ---
print("Hello, {}! You scored {}.".format(name, score))

# --- % formatting (oldest, avoid in new code) ---
print("Name: %s, Age: %d" % (name, age))
▶ Output
Name: Alice, Age: 25
Next year she will be 26
Score: 98.5
Hello, Alice! You scored 98.5.
Name: Alice, Age: 25

Checking String Content

Python has methods that return True or False to check what a string contains.

checking.py
# Check if string contains only digits
print("12345".isdigit())    # True
print("12.5".isdigit())     # False  (dot is not a digit)

# Check if string contains only letters
print("Hello".isalpha())    # True
print("Hello2".isalpha())   # False

# Check if string is all letters + digits
print("Hello2".isalnum())   # True

# Check for uppercase / lowercase
print("HELLO".isupper())    # True
print("hello".islower())    # True

# Check if a sub-string is inside
print("cat" in "the cat sat")   # True
print("dog" in "the cat sat")   # False

# Check start / end
url = "https://python.org"
print(url.startswith("https"))   # True
print(url.endswith(".com"))      # False
▶ Output
True
False
True
False
True
True
True
True
False
True
False

Split & Join

split() breaks a string into a list of parts. join() does the opposite — it merges a list of strings into one.

split_join.py
# --- split() ---
sentence = "apple banana cherry"
words = sentence.split()        # split on spaces by default
print(words)                     # ['apple', 'banana', 'cherry']

csv_line = "10,20,30,40"
numbers = csv_line.split(",")   # split on comma
print(numbers)                   # ['10', '20', '30', '40']

# --- join() ---
fruits = ["apple", "banana", "cherry"]
print(", ".join(fruits))          # join with comma+space
print(" | ".join(fruits))         # join with pipe
print("".join(fruits))            # join with no separator
▶ Output
['apple', 'banana', 'cherry']
['10', '20', '30', '40']
apple, banana, cherry
apple | banana | cherry
applebananacherry

Escape Characters

Some characters need a backslash \ to be included inside a string. These are called escape sequences.

escape_chars.py
# \n  → newline
print("Line 1\nLine 2\nLine 3")

# \t  → tab
print("Name:\tAlice")
print("Score:\t98")

# \'  and \"  → include quotes inside a string
print('It\'s a beautiful day')
print("She said \"hello\"")

# \\  → a literal backslash
print("C:\\Users\\Alice\\Documents")
▶ Output
Line 1
Line 2
Line 3
Name:    Alice
Score:   98
It's a beautiful day
She said "hello"
C:\Users\Alice\Documents

Strings are Immutable

Once a string is created, you cannot change individual characters in it. Any operation that "modifies" a string actually creates a brand-new string.

immutability.py
name = "Alice"

# This will cause an error:
# name[0] = "B"   ← TypeError: 'str' object does not support item assignment

# Correct way: create a new string
new_name = "B" + name[1:]   # "B" + "lice"
print(new_name)               # "Blice"

# The original is untouched
print(name)                   # still "Alice"

# Methods also return new strings — they don't change the original
greeting = "hello"
upper    = greeting.upper()
print(greeting)               # "hello" — unchanged
print(upper)                  # "HELLO" — new string
▶ Output
Blice
Alice
hello
HELLO
Key Concept: Strings are immutable — they cannot be changed in-place. Every string method returns a new string. Always assign the result back if you want to keep it: s = s.upper()

Putting It All Together

A small program that uses many string operations at once.

mini_program.py
# Simple Name Card Generator

raw_input = "  alice sharma  "

# 1. Clean up the input
clean = raw_input.strip().title()   # "Alice Sharma"

# 2. Split into parts
parts      = clean.split()           # ["Alice", "Sharma"]
first_name = parts[0]               # "Alice"
last_name  = parts[1]               # "Sharma"

# 3. Create initials
initials = first_name[0] + "." + last_name[0] + "."  # "A.S."

# 4. Build a card using f-string
border = "=" * 30
print(border)
print(f"  Name     : {clean}")
print(f"  Initials : {initials}")
print(f"  Username : {first_name.lower()}_{last_name.lower()}")
print(f"  Length   : {len(clean)} characters")
print(border)
▶ Output
==============================
  Name     : Alice Sharma
  Initials : A.S.
  Username : alice_sharma
  Length   : 12 characters
==============================
